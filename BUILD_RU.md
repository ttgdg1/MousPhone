# MousPhone 3.3 beta — сборка на Windows и GitHub

## Android Studio или PowerShell

1. Распакуйте ZIP и откройте в Android Studio папку **PocketPad**, где находится `settings.gradle`.
2. Выберите **JDK 17** для Gradle. Установите через SDK Manager **Android SDK Platform 35** и **Build Tools 34.0.0**. Wrapper **Gradle 8.9** включён; первая загрузка инструментов и зависимостей требует интернета.
3. Выполните из папки проекта:

   ```powershell
   powershell -ExecutionPolicy Bypass -File tests/run-tests.ps1
   .\gradlew.bat assembleDebug lintDebug
   ```

   Для первой команды `JAVA_HOME` должен указывать на JDK 17, либо `java` и `javac` должны быть доступны в PATH. В Android Studio можно отдельно выбрать **Build APK(s)**.

4. APK находится в **`app/build/outputs/apk/debug/app-debug.apk`**. Установите его на Android 9+. Версия — **3.3-beta**, versionCode **11**; applicationId `io.pocketpad.remote` сохранён. Совпадающий прежний тестовый ключ позволяет обновить бета-версию с сохранением настроек. Для релиза используйте свой ключ подписи.

Эмулятор для сборки APK не нужен. Физическая Bluetooth-связь с ПК проверяется отдельно; текущие результаты сборки и проверок перечислены в [CHECKS_RU.md](CHECKS_RU.md).

## Выложить исходники на GitHub и собрать APK

1. Создайте репозиторий, например **MousPhone-Android**. Public открывает код всем; Private оставляет доступ приглашённым.
2. Через **Add file → Upload files** загрузите **содержимое папки PocketPad**, включая `.github`, `app`, `gradle`, `tests`, `tools`, `gradlew`, `gradlew.bat` и файлы проекта. Сам ZIP и внешнюю папку дополнительным уровнем загружать не нужно. Сохраните **Commit changes** в основную ветку.
3. Проверьте, что `settings.gradle` и `.github/workflows/build-apk.yml` находятся в корне репозитория.
4. Откройте **Actions → Build debug APK → Run workflow**. Сценарий запускается также при загрузке изменений. Он выполняет шесть JVM-наборов проверок, компиляцию APK и lint.
5. При успешном запуске скачайте **Artifacts → MousPhone-debug-apk**, распакуйте архив и установите APK. Если сборка завершилась ошибкой, откройте упавший шаг и сохраните текст ошибки для исправления.

Не загружайте локальные `build`, `.gradle`, `.idea` и `local.properties`; в поставляемом ZIP их нет. Тестовый ключ уже включён в проект для совместимости личных бета-сборок.

## Язык интерфейса и раскладки ПК

**Всё настраивается в телефоне. На ПК не нужны программа, сервер, скрипт, импорт или экспорт.**

- `⚙` → **Язык интерфейса**: Авто / Русский / English / Deutsch / Français / Español. Авто выбирает поддерживаемый язык телефона, иначе English. Переключение интерфейса сохраняет Bluetooth-контроллер и настройки панелей.
- `⚙` → **Раскладки ПК и порядок Win+Пробел**: добавьте и расположите раскладки так же, как уже настроено в Windows. Нажмите на элемент для перемещения выше/ниже или удаления, `＋` добавляет раскладку. Поддерживаются **US, RU, UK, DE, FR и ES (Испания)**. Точные варианты и KLID приведены в [README.md](README.md).
- Можно оставить **любую пару**, например **ES → EN**, или список из **3–6** раскладок, например **RU → DE → EN**. Одна раскладка допустима без переключения. Исходный список при обновлении — RU → EN.
- Откройте Блокнот, выключите **Caps Lock** и нажмите `⌨`. Удержанием кнопки раскладки слева укажите текущую раскладку окна Windows. Эта сверка не отправляет клавиши на ПК.
- Короткое нажатие отправляет **Win+Пробел**, отпускает клавиши и ждёт **350 мс**, затем переходит к следующей ожидаемой раскладке списка. Если раскладка не входит в список или в нём только одна, переключение не отправляется.
- Приложение **не получает** список раскладок и текущий язык Windows. После ручной смены языка/окна на ПК снова выполните сверку. Язык Android-клавиатуры выбирается отдельно.

Быстрые команды над вводом и нижняя панель редактируются независимо; обе можно полностью скрыть в `⚙` и вернуть без потери команд. Backspace находится справа от ввода, язык — слева, Enter — внизу и на системной клавиатуре. Название и иконка MousPhone сохранены.

## Проверка ввода после установки

Проверьте в соответствующей раскладке: **EN** `Hello, world!`, **RU** `Привет, мир! №3`, **UK** `£ € @`, **DE** `Grüße, äöüß`, **FR** `été, forêt, È`, **ES** `¡Hola! niño, áéíóú, ¿sí?`. Проверьте удаление, Enter, смену языка и сохранение вашего порядка после перезапуска.

Это HID-ввод физических клавиш, а не универсальный Unicode. Акценты передаются завершёнными последовательностями, AltGr — правым Alt; эмодзи и несовместимое изменение отклоняются до отправки. В старой французской AZERTY с выключенным Caps Lock, например, **É, Ç, œ, æ недоступны**. Если связь оборвалась посреди акцента, проверьте окно ПК: перед продолжением может понадобиться Esc. Очистка локального фрагмента при сверке или отправке команды не удаляет текст на ПК.

Также проверьте тачпад, двухпальцевую прокрутку, двойной тап с перетаскиванием, скрытие/возврат панелей и переподключение Bluetooth на физических устройствах. Файлы `tools/layouts` предназначены только для разработчика, а не для работы пульта.
