# Проверка MousPhone 3.3 beta

Дата: 26 октября 2026 года. Платформа разработки — Windows.

- **Сборка APK:** assembleDebug успешно. JDK 17, Gradle 8.9, AGP 8.7.3, SDK Platform 35, Build Tools 34.0.0. Версия 3.3-beta, versionCode 11, applicationId io.pocketpad.remote.
- **Android Lint:** успешно, 0 ошибок и 24 предупреждения. Проверки не подавлялись. Для переключения языков без загрузок отключено разделение языковых ресурсов в будущих App Bundle.
- **JVM:** все шесть наборов прошли: CheckHid, CheckLayouts, CheckHostLayouts, CheckLiveText, CheckPointerMotion, CheckTapSequence. Подтверждены 757 поддерживаемых символов шести Windows-раскладок, 124 законченные dead-key-последовательности, AltGr и ISO-клавиша, реальные HID-байты, сохранение/цикл раскладок, атомарный отказ несовместимого ввода, испанские/французские/немецкие правки текста, движение и двойной тап.
- **Таблицы:** данные получены из статических таблиц установленных Windows layout DLL без изменения активной раскладки и без внедрения нажатий. Android использует готовые Java-таблицы; пользователь ничего на ПК для этого не запускает. Декодирование проверено по отдельной прямой таблице событий и контрольным физическим клавишам. Microsoft DLL в поставку не входят.
- **Переводы:** 139 переводимых ключей в каждом из пяти наборов EN/RU/DE/FR/ES; аргументы форматирования совпадают. Имя MousPhone общее. Изменение языка интерфейса сохраняет экземпляр Bluetooth-контроллера; статусы обновляются с учётом выбранной локали.
- **Брендинг и совместимость:** имя MousPhone и иконка сохранены. SHA-256 исходного PNG совпадает с 3.2.1. Прежний тестовый сертификат подписи сохранён; HID-дескриптор остаётся 119-байтным, мышь — 4 байта, клавиатура — 8 байт.

## Интерфейс в изолированном эмуляторе

Проверки выполнены на отдельном headless/read-only Android API 37. Личный AVD и физические устройства не изменялись.

- Установка 3.2.1, сохранение обеих скрытых панелей, US-раскладки, скорости 2.0 и разных пользовательских команд верхней/нижней панели, затем обновление до 3.3 без удаления данных: всё сохранилось.
- Через настоящий UI выбраны Русский, English, Deutsch, Français, Español и Auto. Переведены настройки, подписи тачпада и Bluetooth-статусы. Для каждого режима проверены сохранение после force-stop/запуска и независимость других настроек. Auto вернул английский язык тестового телефона.
- Проверены отдельное скрытие верхней/нижней панели, скрытие обеих, восстановление и независимость сохранённых сочетаний. Скрытые строки не оставляют своих элементов.
- Через UI добавлены, удалены и переставлены раскладки: RU/US → RU/US/ES → US/ES → ES/US → ES/US/DE → ES/DE/US → ES/US. Значения проверены в сохранённых настройках.
- Ручная сверка показывает все шесть раскладок; выбор ES и порядок ES/US сохраняются после перезапуска. Любая успешная сверка очищает только локальный фрагмент, включая повторный выбор той же раскладки.
- Просмотрены снимки настроек DE/FR/ES, обеих панелей, списка шести раскладок и списка из трёх. При основном прогоне дефектов интерфейса не найдено.

Дополнительная проверка финального APK также прошла:

- При выключенном Bluetooth отказ Deny возвращает в приложение без зацикливания системного запроса. Языки EN → RU → FR переключают и текст этой ошибки; Bluetooth остаётся выключенным.
- При отсутствии разрешения проверен перевод статуса FR → EN → RU. Панели, скорость, ES и порядок ES/US сохраняются; перезапуск сохраняет французский интерфейс и настройки.
- Исправлены обновление локального статуса при смене языка до запуска HID и повторный запрос после отказа включить Bluetooth. Изолированный эмулятор после проверки остановлен.

## Что осталось для реальных устройств

Эмулятор не подтверждает настоящую Bluetooth HID-связь с Windows. Доставку Win+Space, фактическое переключение раскладки, AltGr, ударения, физические жесты, IME/автокоррекцию и радиопереподключение нужно проверить на телефоне и ПК. Изменение системного языка телефона во время работы Auto отдельно не испытывалось.

HID не сообщает приложению язык или список раскладок Windows. Нужны правильный порядок на телефоне, ручная сверка и выключенный Caps Lock. Возможности зависят от конкретного варианта раскладки; старый FR AZERTY не поддерживает É, Ç, œ, æ этим способом. Эмодзи и произвольный Unicode не обещаются. После обрыва посреди ударения может понадобиться Esc в редакторе ПК.

На холодном старте эмулятор работал медленно из-за давления на память; краткий системный экран Updating и один timeout UIAutomator не были падениями MousPhone. Все проверки выполнялись только в рабочем тестовом окружении.
